# Debugging Practice Suite 🛠️

A professional-grade repository dedicated to systematic debugging, code optimization, and algorithmic problem-solving.

## Overview
This repository provides examples of common programming challenges, demonstrating best practices in:
- **Error Handling:** Implementing robust try-except blocks and logging.
- **Complexity Analysis:** Writing algorithms with optimized time and space complexity.
- **Clean Code:** Adhering to PEP 8 standards and writing self-documenting code.

## Featured Utilities
### `factorial_optimizer.py`
A robust utility that calculates factorials while handling potential recursion limit exceptions and non-integer inputs.

## Getting Started
1. Clone the repository: `git clone https://github.com/vineethguguloth/debugging-practice-suite.git`
2. Navigate to the directory: `cd debugging-practice-suite`
3. Run the script: `python factorial_optimizer.py`
